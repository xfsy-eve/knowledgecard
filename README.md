# 知识卡片生成器

把一个知识点、一段笔记或一份学习资料，整理成一张看得清、读得懂的中文知识卡。可以用来复习、给孩子讲解，也可以整理自己的学习笔记。

你可以指定科技风、手绘笔记风等样式。没有特别要求时，默认生成 **3:4 中文手绘笔记风 PNG 图片**。

## 第一次用，先填一个知识点

```text
使用 $knowledge-card-generator，把“【填写知识点】”做成一张 3:4 中文知识卡。
```

把“【填写知识点】”换成“月相”“分数”或其他想学的内容，就可以开始。想指定风格、给谁看或重点讲什么，在后面补一句就好。

技能已配置这条起始提示词。在支持默认提示词的软件中，选用技能时可以带入输入框；如果没有自动出现，直接复制上面这句即可。若只选了技能、还没告诉它主题，它会先问你想做哪个知识点，不用填写一长串信息。

## 挑一个例子，直接试试

### 月相：科技风

```text
使用 $knowledge-card-generator，把“月相”做成 3:4 的科技风知识卡。
```

### 狭义相对论：手绘笔记风

```text
使用 $knowledge-card-generator，把“狭义相对论”制作成一张 3:4 中文手绘笔记风知识卡，包含定义、图解、生活案例和易错点。
```

### 分数：讲给小学生听

```text
使用 $knowledge-card-generator，给小学三年级孩子做一张“分数的意义”知识卡，使用 3:4 彩色手绘风。用分蛋糕的例子讲清整体、平均分和几分之几，文字短一点。
```

### 欧姆定律：复习公式和易错点

```text
使用 $knowledge-card-generator，给初中生做一张 3:4 的“欧姆定律”知识卡，包含公式、单位、简单电路图、一道生活例题和易错点，采用手绘笔记风。
```

### 自己的笔记：整理成复习卡

先附上笔记或学习资料，再发送：

```text
使用 $knowledge-card-generator，根据我上传的笔记制作中文复习知识卡，保留关键定义、公式和易错点，采用 3:4 简洁科技风。内容多时请拆成几张，不要把字挤小。
```

生成后还可以接着说：“这张给小学生看，再少一点文字。”或“保留知识内容，把配色改得柔和一些。”拿到图片后，一起检查文字、公式、数字和图解是否准确。

## 安装与生图工具

需要使用支持安装或加载 Skill 的 AI 软件。将下面这段话发给它：

```text
请帮我安装知识卡片生成器。
项目地址：https://github.com/xfsy-eve/knowledgecard
技能文件夹：knowledge-card-generator
请按当前软件支持的方式安装，检查文件是否完整，并告诉我能使用哪种生图工具。
```

生成图片时，**优先使用 ImageGen；没有可用的 ImageGen 时，使用当前模型默认的生图工具**。使用者不用自己选择工具。如果当前环境没有任何可用的生图工具，技能会说明情况，并整理可复制的出图提示词和文案，方便你交给能生图的软件继续完成。
