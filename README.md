# 知识卡片生成器

把一个知识点、一段笔记或一份学习资料，整理成中文手绘笔记风的 PNG 知识卡。默认比例为 3:4，适合手机阅读，也可以用来复习、讲解或分享。

## 安装

需要使用支持 Skill、且能调用内置 ImageGen 的 AI 工具。将下面这段话发给它：

```text
请帮我安装知识卡片生成器。
项目地址：https://github.com/xfsy-eve/knowledgecard
技能文件夹：knowledge-card-generator
请确认你支持 Skill 和内置 ImageGen，并检查是否安装成功。
```

## 开始使用

```text
请用 $knowledge-card-generator，给初中生做一张欧姆定律知识卡，包含公式、生活例子和易错点，使用默认的 3:4 比例。
```

也可以附上自己的笔记，说明给谁看、想保留哪些内容。拿到图片后，记得一起看看文字、公式和数字是否准确。
