# ImageGen 知识卡内容稿

内容稿用于锁定事实和构造提示词，不是渲染器输入，也不是最终成品。可使用以下 JSON 结构在内部整理：

```json
{
  "version": 2,
  "topic": "欧姆定律",
  "audience": "初中生",
  "ratio": "3:4",
  "title": "欧姆定律：电路里谁在较劲？",
  "subtitle": "初中物理 · 电学核心考点",
  "modules": [
    {
      "heading": "核心定义",
      "kind": "definition",
      "verbatim_lines": ["I = U / R", "I：电流，单位 A"],
      "visual": "电池、电阻和灯泡组成的简单电路，箭头表示电流方向"
    }
  ],
  "footer": "先找不变量，再选公式",
  "fact_locks": ["I = U / R", "电阻单位是 Ω"],
  "avoid": ["平台水印", "无关英文", "伪文字"]
}
```

## 字段原则

- `ratio`：默认 `3:4`，也可按用户要求使用 `1:1`、`9:16` 或 `4:3`。
- `title`：建议 8–22 个汉字，一行或两行内读完。
- `subtitle`：可选，用于说明学科、受众或学习目标。
- `modules`：单张 4–6 个；定义、公式、图解、案例、易错点分别成块。
- `kind`：可用 `definition`、`formula`、`diagram`、`steps`、`example`、`warning`、`summary`。
- `verbatim_lines`：最终图片中必须逐字出现的文字。每条尽量 8–28 个汉字。
- `visual`：告诉 ImageGen 画什么关系或场景，不能只写“配一张图”。
- `fact_locks`：润色和重生成时都不能改变的公式、数字、专有名词和条件。

## 密度边界

- 单张建议 12–20 条正文；每模块 2–4 条。
- 核心公式独占一行，复杂推导拆页。
- 连续三段长句、超过 20 条正文或超过 6 个模块时，优先拆成系列卡。
- 不通过删除限定条件来缩短定义。

## 推荐顺序

核心定义 → 关键公式或结构 → 图解 → 生活案例 → 易错点 → 一句总结。不同学科可调整，但第一张必须能独立说明主题。
