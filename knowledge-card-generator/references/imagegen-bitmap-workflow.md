# ImageGen 位图生成与验收

本 Skill 的最终图片直接由内置 `image_gen` 生成。内容稿、提示词和检查清单可以由模型整理，但不能用代码重新排版或覆盖图片。

## 最终生成提示词结构

```text
Use case: scientific-educational
Asset type: final Chinese knowledge-card PNG
Primary request: 为“<主题>”生成一张可直接交付的中文手绘教辅知识卡
Audience: <受众>
Scene/backdrop: 米黄色活页笔记纸，轻微纸张纹理，少量文具装饰
Style/medium: hand-drawn educational infographic, clean Chinese handwriting, polished raster illustration
Composition/framing: 精确 <比例> 竖版；标题区清楚；4–6 个模块按阅读顺序排列；留足边距
Color palette: 深蓝、砖红、柔和黄、灰绿色
Text (verbatim):
- "<标题>"
- "<副标题>"
- "<模块标题与每一条正文，逐条列出>"
- "<公式、数字、单位和页脚>"
Diagram requirements: <需要表达的关系、箭头方向和生活场景>
Constraints: 所有引号内文字逐字呈现；不得增删改；中文清晰；公式准确；无裁切；最终就是完整成品
Avoid: 错别字、伪文字、乱码、额外英文、无关公式、水印、Logo、平台 UI、极小字号、拥挤排版
```

## 生成前降密度

- 每个模块保留一个结论和 2–4 条短句。
- 公式独占一行，变量解释尽量拆成短标签。
- 生僻术语、上下标、希腊字母和单位放入逐字文案表，不让模型自由改写。
- 一张图需要超过 20 条正文或多个长公式时，先拆成系列卡。

## 逐字验收

逐项查看实际图片：

1. 标题和副标题是否完整。
2. 用户要求的定义、图解、案例、易错点是否都出现。
3. 每个汉字、数字、符号、单位和公式是否与逐字文案表一致。
4. 箭头方向和因果关系是否正确。
5. 是否存在重复模块、伪文字、无关英文、水印或 Logo。
6. 四边是否完整，比例是否符合要求，手机缩略图下正文是否可读。

## 修正规则

- 单个错字或局部漏字：编辑原图，明确“只修改这一处，其余像素级保持不变”。
- 多处文字错误但布局可用：一次只修一个模块，避免全图漂移。
- 结构错误或文字过密：缩短文案或拆页后重新生成，不用程序覆盖文字。
- 最多两次局部编辑；之后只允许一次降密度重生成。
- 所有尝试仍未通过时，明确说明未达到逐字验收，不把问题图标为最终成品。

## 保存与报告

- 内置 ImageGen 默认输出位于 Codex 生成图片目录；项目成品必须复制到工作区。
- 不覆盖旧成品，使用带版本或主题的文件名。
- 最终回复包含：成品路径、是否通过逐字验收、最终提示词摘要、使用“内置 ImageGen”生成。
